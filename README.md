# বাজার দর (BazarDor)

BazarDor is a web application designed to help users explore the prices of essential daily products in Bangladesh. It provides a simple way to browse products by category and compare prices, helping users stay informed about everyday market rates.

## Technologies Used

- **Next.js** – React framework with the App Router.
- **React** – Component-based user interface.
- **TypeScript** – Type-safe development.
- **Tailwind CSS** – Utility-first styling.
- **daisyUI** – UI components built on Tailwind CSS.
- **MongoDB Atlas** – Cloud database.
- **Better Auth** – Authentication and session management.
- **Lucide React** – Icons.
